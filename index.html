Unified advertising data from DV360, LinkedIn and Meta

Advertising technology client, Zensar Technologies, 2022 to 2024

Problem
Campaign data arrived from several ad platforms in different formats, schemas and metric definitions, and some platforms only sent reports by email.
What I built
Python ingestion from each platform's REST API, plus automated collection of emailed CSV and Excel reports, all landing in the same SQL staging layer. PostgreSQL transformations merged everything into one common model, orchestrated by Airflow DAGs with retries, alerting and backfills.
Result
One reporting layer across all platforms, with reconciliation checks that catch missed pulls, partial loads and source-side discrepancies.

  • REST APIs
  • PostgreSQL
  • Apache Airflow
  • Power BI
  • Domo

Log-level ad data on Google Cloud

Advertising technology client, Zensar Technologies, 2022 to 2024

Problem
Impression and event-level files from ad platforms were too granular to report on directly.
What I built
Cloud Storage buckets to receive log-level transfer files, BigQuery datasets over them, and SQL that rolls impressions, clicks and conversions up to campaign-level metrics.
Result
Granular log data feeding the same downstream fact and dimension tables as the API data.
  • GCP Cloud Storage
  • BigQuery
  • SQL
  • Dimensional modelling

Legacy ETL migration to Azure for Guidewire insurance data

Multifamily housing insurance client, Zensar Technologies

Problem
A legacy ETL process moved Guidewire claims and policy data from AWS S3 to on-premise SQL Server, too slowly for near real-time analytics and planned ML work.
What I built
I led the migration to a reusable framework of parameterised Azure Data Factory pipelines and Databricks SQL notebooks, supporting incremental and delta loads across raw and curated zones, with data quality checks in Databricks.
Result
Near real-time data availability, validated through full and incremental load testing against an audit framework, with Power BI and SSRS reporting on top.
  • Azure Data Factory
  • Databricks
  • AWS S3
  • SQL Server
  • Power BI

Association CRM data integration on Microsoft Dynamics

ProTech association management platform, R Systems, 2024 to present

Problem
Membership data came in as CSV, Excel and flat files and was loaded by hand, leaving duplicate and inconsistent member records across modules.
What I built
SSIS packages with the KingswaySoft toolkit that load and upsert memberships, committees, chapters, accounts, contacts and sponsorships into Dynamics, with validation and cleansing built in. Parameterised SSRS reports use FetchXML directly against the CRM.
Result
Recurring loads that run without manual file processing, and reports on membership growth, sponsorship revenue and committee engagement.
  • SSIS
  • KingswaySoft
  • Dynamics 365
  • SSRS
  • FetchXML
